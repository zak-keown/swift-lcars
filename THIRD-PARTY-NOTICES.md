# Third-party material

## LCARS GTJ3 font

Author: GTJLCARS.de. Source and terms: https://www.gtjlcars.de/LCARSindex/LCARSFONTS.htm

Archive: https://www.gtjlcars.de/LCARSGTJ3.zip (retrieved 2026-09-29).

The author describes the font as freeware, permits its use, and prohibits renaming, modifying or selling the font files. Attribution to GTJLCARS.de is retained in the font; the author requests a backlink when used in websites or software. The font remains under those terms, separate from this project's original code.

`Sources/SwiftLCARS/Resources/LCARSGTJ3.ttf` is the unmodified file from that archive. SHA-256: `dc3ce89ae19ff3cc2169cb7bd36311adaa4ca2698eaca01a9bb47fb7d62ad4bb`.

The package registers the font inside the consuming process and never installs it system-wide. This is a fan-designed typeface, not a claim that it is an official production font.

## Palette seeds and LCARS attribution

The era palette seeds are attributed to https://www.thelcars.com/colors.php. Semantic role assignments and contrast handling are authored for this project. LCARS was created by Michael Okuda for Star Trek. This project is independent and unofficial.
